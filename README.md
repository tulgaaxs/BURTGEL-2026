# Warehouse Management System

A web-based warehouse inventory project developed for learning and practice.

## 1. Төслийн тухай

Энэхүү систем нь агуулахад байгаа бараа бүтээгдэхүүний мэдээллийг бүртгэх, барааны хөдөлгөөнийг хянах, үлдэгдлийг тооцоолоход чиглэнэ. Ингэснээр агуулахын үйл ажиллагааг илүү эмх цэгцтэй зохион байгуулж, шаардлагатай мэдээллийг нэг дороос авах боломж бүрдэнэ.

## 2. Системийн хэрэглэгчид

Системийг дараах үндсэн хэрэглэгчид ашиглана.

- **Агуулахын нярав:** Бараа шинээр бүртгэх, орлого зарлагын мэдээлэл оруулах, үлдэгдэл шалгах.
- **Менежер:** Барааны мэдээлэл болон агуулахын нөөцийн төлөвийг хянах.
- **Администратор:** Хэрэглэгчийн эрх, бүртгэл болон системийн тохиргоог хариуцах.

## 3. Технологийн сонголт

Төслийн хөгжүүлэлтэд дараах технологиудыг ашиглахаар төлөвлөсөн.

| Технологи | Ашиглах зориулалт |
|---|---|
| JavaScript | Веб интерфейсийн үйлдэл, хэрэглэгчтэй харилцах хэсгийг боловсруулах |
| Node.js | JavaScript ашиглан сервер талын ажиллагааг хэрэгжүүлэх орчин |
| Python | Өгөгдөл боловсруулах болон системийн үндсэн логикийг бичих |
| FastAPI | Серверийн API үүсгэж, хүсэлт болон хариуг боловсруулах |
| SQLAlchemy | Програмын кодоос өгөгдлийн сантай холбогдох ажиллагааг зохицуулах |
| MySQL | Бараа бүтээгдэхүүн болон агуулахын бүртгэлийн мэдээллийг хадгалах |

## 4. Системийн ерөнхий ажиллагаа

Систем нь веб интерфейс, серверийн API болон өгөгдлийн сан гэсэн үндсэн хэсгүүдтэй байна.

Хэрэглэгч интерфейсээр дамжуулан мэдээлэл оруулах эсвэл хайлт хийхэд сервер хүсэлтийг боловсруулна. Шаардлагатай өгөгдлийг MySQL сангаас авч, үр дүнг хэрэглэгчид буцаан харуулна.

## 5. Хөгжүүлэлтийн орчин

Төсөлд ашиглах програм хангамж, хөгжүүлэлтийн хэрэгсэл болон орчны талаарх дэлгэрэнгүй мэдээллийг [`docs/environment.md`](docs/environment.md) файлаас үзнэ үү.

## 6. Мэдээллийн аюулгүй байдал

Төслийн код болон өгөгдлийг хамгаалахын тулд нууц үг, API token, `.env` файл, өгөгдлийн сангийн нөөц хуулбар зэрэг эмзэг мэдээллийг GitHub repository-д оруулахгүй. Нууц тохиргоог тусад нь хадгалж, шаардлагатай үед `.gitignore` файл ашиглана.

## 7. Төслийн зорилго

Энэ төслөөр дамжуулан веб системийн бүтэц, API хөгжүүлэлт, өгөгдлийн сантай ажиллах болон GitHub ашиглан хамтран хөгжүүлэх үндсэн ойлголтуудыг эзэмших зорилготой.
