# Development Environment

## Ашиглаж буй технологи

Энэ төсөлд дараах технологиудыг ашиглана:

- JavaScript / Node.js
- Python
- MySQL
- Git
- GitHub

## Хувилбар шалгах

Компьютер дээр суулгасан хувилбаруудыг дараах командаар шалгана.


```bash
node --version
python --version
mysql --version
git --version
```

1. MySQL database-ийг ажиллуулна.
2. Backend орчныг бэлтгэнэ.
3. Backend серверийг ажиллуулна.
4. Frontend хэсгийг ажиллуулна.

## Нууц мэдээлэл

`.env` файл, password, API token болон database dump зэрэг нууц мэдээллийг GitHub repository-д commit хийхгүй.


## Бодитоор шалгасан орчны хувилбарууд

Дараах командуудыг өөрийн хөгжүүлэлтийн компьютер дээр ажиллуулаад гаралтыг яг хэвээр нь бөглөнө. Одоогоор энэ репозитороос таны компьютерийн суулгасан хувилбарыг мэдэх боломжгүй тул үр дүнг зориуд хоосон үлдээв.

| Команд | Бодит гаралт | Шалгасан огноо |
|---|---|---|
| `node --version` | _Ажиллуулаад бөглөнө_ | _Огноо_ |
| `python --version` | _Ажиллуулаад бөглөнө_ | _Огноо_ |
| `mysql --version` | _Ажиллуулаад бөглөнө_ | _Огноо_ |
| `git --version` | _Ажиллуулаад бөглөнө_ | _Огноо_ |

**Анхаарах нь:** Эдгээр командыг ажиллуулж гаралтыг нэмсний дараа л орчны хувилбарууд баталгаажсан гэж тэмдэглэнэ. Команд олдохгүй бол алдааны гаралтыг мөн тэмдэглэж, суулгах шаардлагатайг бичнэ.
