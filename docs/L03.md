
 L03 — Асуудал ба процесс

Хэрэглэгчийн үүрэг

1. Агуулахын нярав
- Шинэ бараа бүртгэнэ.
- Барааны орлого, зарлагын баримт үүсгэнэ.
- Барааны тоо хэмжээ болон мэдээллийг шалгана.

2. Менежер
- Агуулахын барааны үлдэгдлийг хянана.
- Орлого, зарлагын тайлан харна.
- Барааны нөөцийг хянана.

3. Администратор
- Хэрэглэгчийн эрхийг удирдана.
- Системийн тохиргоог хариуцна.
- Үйлдлийн түүхийг хянана.

Гарч болох асуудлууд

**1. Ижил SKU давхар бүртгэгдэх**

Нэг барааг ижил кодоор олон удаа бүртгэх эрсдэлтэй.

2. Үлдэгдэл буруу гарах

Орлого, зарлагын мэдээлэл буруу бүртгэгдсэнээс үлдэгдэл бодит тооноос зөрж болно.

3. Барааны тоо хүрэлцэхгүй байх

Агуулахад байгаа тооноос их барааг зарлагаар гаргах эрсдэлтэй.

4. Баримт буруу засагдах

Баталгаажсан баримтын мэдээллийг өөрчлөхөөс хамгаалах шаардлагатай.

5. Бүртгэлгүй бараа ашиглагдах

Системд бүртгэгдээгүй барааг орлого, зарлагад ашиглах эрсдэлтэй.

6. Хэрэглэгчийн эрх буруу ашиглагдах

Эрхгүй хэрэглэгч мэдээлэл өөрчлөх эрсдэлтэй.

Одоогийн процесс

Бараа ирэх → Барааны мэдээлэл шалгах → SKU шалгах → Бараа бүртгэх → Орлогын баримт үүсгэх → Баримт батлах → Үлдэгдэл нэмэгдэх → Зарлагын хүсэлт үүсгэх → Үлдэгдэл шалгах → Зарлага бүртгэх → Үлдэгдэл хасагдах.

Оролт ба гаралт

1. Бараа бүртгэх
Оролт: Барааны нэр, SKU, ангилал, үнэ.

Процесс: Барааны мэдээлэл шалгаж, SKU давхардсан эсэхийг шалгана.

Гаралт: Бараа амжилттай бүртгэгдэх эсвэл алдаа гарах.

2. Бараа орлого бүртгэх
Оролт: Барааны SKU, тоо хэмжээ, нийлүүлэгч.

Процесс: Барааны мэдээлэл шалгаж, орлогын баримт үүсгэнэ.

Гаралт: Барааны үлдэгдэл нэмэгдэнэ.

3. Бараа зарлага бүртгэх
Оролт: Барааны SKU, зарлагын тоо хэмжээ.

Процесс: Үлдэгдэл хүрэлцэж байгаа эсэхийг шалгана.

Гаралт: Зарлага амжилттай бүртгэгдэх эсвэл алдаа гарах.

4. Үлдэгдэл шалгах
Оролт: Барааны болон агуулахын мэдээлэл.

Процесс: Барааны одоогийн үлдэгдлийг тооцоолно.

Гаралт: Барааны үлдэгдлийн мэдээлэл гарна.

Миний дүгнэлт

Энэ хичээлээр агуулахын системийн хэрэглэгчид болон тэдгээрийн үүргийг тодорхойлсон. Мөн бараа бүртгэх, орлого, зарлага хийх үед гарч болох асуудлуудыг судалсан.

L03 шалгалт

Системийн хэрэглэгчийн үүрэг, үндсэн процесс болон гарч болох асуудлуудыг тодорхойлсон.
