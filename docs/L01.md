L01 

Warehouse Management System — Агуулахын удирдлагын систем

Төслийн зорилго

Энэхүү төслийн зорилго нь агуулахад байгаа бараа бүтээгдэхүүний мэдээллийг бүртгэх, барааны орлого зарлагыг хянах, үлдэгдлийг тооцоолох боломжтой веб систем боловсруулах юм.

Системийг ашигласнаар барааны мэдээллийг нэг дор хадгалж, агуулахын үйл ажиллагааг илүү хялбар, хурдан зохион байгуулах боломжтой.

Төслийн үндсэн боломжууд

Шинэ бараа бүртгэх.
Барааны мэдээлэл харах, хайх.
Барааны орлого бүртгэх.
Барааны зарлага бүртгэх.
Барааны үлдэгдэл шалгах.
Орлого, зарлагын баримт хөтлөх.
Тайлан болон үйлдлийн түүх харах.
Хэрэглэгчийн эрх удирдах.

Хэрэглэгчид

Агуулахын нярав: Бараа бүртгэх, орлого зарлага хийх.

Менежер: Барааны үлдэгдэл болон тайлан хянах.

Администратор: Хэрэглэгчийн эрх болон системийг удирдах.

Ашиглах технологи

JavaScript — Веб интерфейс.
Node.js — Сервер талын ажиллагаа.
Python — Системийн логик болон өгөгдөл боловсруулах.
FastAPI — API боловсруулах.
SQLAlchemy — Өгөгдлийн сантай холбогдох.
MySQL — Мэдээлэл хадгалах.

Миний дүгнэлт

Энэ хичээлээр агуулахын удирдлагын системийн зорилго, үндсэн боломж болон хэрэглэгчдийн үүргийг ойлгосон.

Мөн төсөлд ашиглах технологиуд болон системийн ерөнхий ажиллагаатай танилцсан.

L01 шалгалт

Энэ хэсэгт төслийн зорилго, хэрэглэгчид, үндсэн боломжууд болон технологийн сонголтыг тодорхойлсон.
