
L01 — Төслийн танилцуулга

 Төслийн нэр
Warehouse Management System — Агуулахын удирдлагын систем

 Төслийн зорилго
Энэхүү төслийн зорилго нь агуулахад байгаа бараа бүтээгдэхүүний мэдээллийг бүртгэх, барааны орлого зарлагыг хянах, үлдэгдлийг тооцоолох боломжтой систем хийх юм.

Системийг ашигласнаар барааны мэдээллийг нэг дор хадгалж, агуулахын ажлыг илүү хялбар болгоно.

 Төслийн үндсэн боломжууд
- Шинэ бараа бүртгэх.
- Барааны мэдээлэл харах, хайх.
- Барааны орлого бүртгэх.
- Барааны зарлага бүртгэх.
- Барааны үлдэгдэл шалгах.
- Орлого, зарлагын баримт хөтлөх.
- Тайлан харах.
- Хэрэглэгчийн эрх удирдах.

Хэрэглэгчид

Агуулахын нярав
- Бараа бүртгэх.
- Орлого, зарлага хийх.

Менежер
- Барааны үлдэгдэл шалгах.
- Тайлан хянах.

Администратор
- Хэрэглэгчийн эрх удирдах.
- Системийн тохиргоо хийх.

 Ашиглах технологи
- JavaScript — Веб интерфейс хийх.
- Node.js — Сервер талын ажиллагаа.
- Python — Өгөгдөл боловсруулах.
- FastAPI — API боловсруулах.
- MySQL — Мэдээлэл хадгалах.

Миний дүгнэлт
Энэ хичээлээр агуулахын удирдлагын систем гэж юу болох, ямар зориулалттай, хэн ашиглах талаар судалсан. Мөн төслийн үндсэн боломжууд болон ашиглах технологиудтай танилцсан.

L01 шалгалт
Төслийн зорилго, хэрэглэгчид, үндсэн боломжууд болон ашиглах технологийг тодорхойлсон.


## Хувийн суралцах зорилго ба хэмжүүр

1. **GitHub-ийн PR урсгал эзэмших.** Энэ төслийн нэг өөрчлөлтийг feature branch дээр commit хийж, PR нээж, өөр оюутнаас review авч, саналын дагуу засвар хийнэ. **Батлах арга:** PR холбоос, review comment болон засварласан commit-ийг хавсаргана.
2. **Draft ба Posted төлөвийг ойлгож тайлбарлах.** Draft баримт үлдэгдэлд нөлөөлөхгүй, Posted баримтыг батлахад үлдэгдэлд нэг удаа нөлөөлнө гэдгийг дор хаяж 3 жишээгээр тайлбарлана. **Батлах арга:** L07-ийн TC-үүд болон L08-ийн тооцооны кейсээр тайлбарлаж шалгана.

Эдгээр зорилгыг биелүүлсэн эсэхийг зөвхөн PR review болон кейсийн тооцоог хийсний дараа тэмдэглэнэ.
