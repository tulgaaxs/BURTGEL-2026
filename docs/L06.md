L06 — Системийн бүтэц ба өгөгдлийн сан

Системийн ерөнхий бүтэц

Агуулахын удирдлагын систем нь үндсэн 3 хэсгээс бүрдэнэ.

1. Frontend

Хэрэглэгчийн харилцах интерфейс. JavaScript ашиглан веб хуудсын үйлдлийг боловсруулна.

2. Backend

Хэрэглэгчээс ирсэн хүсэлтийг хүлээн авч боловсруулна. Python болон FastAPI ашиглан API үүсгэнэ.

3. Database

Бараа, хэрэглэгч, орлого, зарлагын мэдээллийг MySQL өгөгдлийн санд хадгална.

Системийн ажиллагаа

Хэрэглэгч веб интерфейсээр мэдээлэл оруулна → Frontend хүсэлтийг Backend рүү илгээнэ → Backend мэдээллийг шалгаж боловсруулна → Database-д хадгална → Үр дүнг хэрэглэгчид буцаана.

Өгөгдлийн сангийн үндсэн хүснэгтүүд

1. Users

user_id — Хэрэглэгчийн дугаар.
username — Нэвтрэх нэр.
password_hash — Нууц үгийн хэш.
role — Хэрэглэгчийн эрх.

2. Products

product_id — Барааны дугаар.
 Барааны код.
name — Барааны нэр.
price — Барааны үнэ.
category — Барааны ангилал.

3. Warehouses

warehouse_id — Агуулахын дугаар.
warehouse_name — Агуулахын нэр.
location — Байршил.

4. Stock

stock_id — Үлдэгдлийн дугаар.
product_id — Барааны дугаар.
warehouse_id — Агуулахын дугаар.
quantity — Үлдэгдлийн тоо.

5. Documents

document_id — Баримтын дугаар.
document_type — Орлого эсвэл зарлага.
status — Баримтын төлөв.
created_by — Баримт үүсгэсэн хэрэглэгч.
created_at — Үүсгэсэн огноо.

6. Document_Items

item_id — Мөрийн дугаар.
document_id — Баримтын дугаар.
product_id — Барааны дугаар.
quantity — Барааны тоо хэмжээ.

7. Audit_Logs

log_id — Үйлдлийн дугаар.
user_id — Үйлдэл хийсэн хэрэглэгч.
action — Хийсэн үйлдэл.
created_at — Үйлдлийн огноо.
reason — Үйлдлийн тайлбар.

Өгөгдлийн холбоо

Users хүснэгт нь Documents болон Audit_Logs хүснэгттэй холбогдоно.
Products хүснэгт нь Stock болон Document_Items хүснэгттэй холбогдоно.
Warehouses хүснэгт нь Stock хүснэгттэй холбогдоно.
Documents хүснэгт нь Document_Items хүснэгттэй холбогдоно.

Миний дүгнэлт

Энэ хичээлээр системийн Frontend, Backend болон Database гэсэн үндсэн бүтцийг ойлгосон.

Мөн агуулахын системд шаардлагатай өгөгдлийн сангийн хүснэгтүүд болон тэдгээрийн холбоог тодорхойлсон.
